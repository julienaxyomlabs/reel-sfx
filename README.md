# reel-sfx

Original, procedural sound effects for short-form video (Reels, TikTok, Shorts, YouTube), plus a tiny Python API
and CLI that put each sound exactly on its frame and tuck it under the dialogue.

- **19 sounds**, including whooshes, risers, impacts, pops, clicks, a bell, a bleep, a drone and a heartbeat.
  They are 48 kHz / 24-bit stereo WAVs, mono-compatible and clip-free.
- **Audio is CC0** (public domain). **Code is MIT.**
- **Every sound is generated by code in this repo.** Its recipe and seed are recorded, and CI re-renders it and
  compares the result against the bundled file. No recordings, samples or analyses of existing sounds are used
  ([provenance](docs/PROVENANCE.md)).
- **One runtime dependency:** NumPy. ffmpeg is only needed for the video example.

## Install

```bash
pip install git+https://github.com/julienaxyomlabs/reel-sfx@v0.1.0
```

Or from a clone: `pip install .`. The WAVs ship inside the package, and `reel-sfx export ./sfx` copies them out
for your editor (Premiere, Resolve, CapCut, Final Cut...).

## Use

```bash
reel-sfx list                                    # id · category · length · anchor · title
reel-sfx path whoosh.soft                        # where the WAV is
reel-sfx export ./sfx                            # all WAVs + sounds.json into a folder
reel-sfx render whoosh.soft --seed 7 --out w.wav # a fresh variation (noise-based sounds)
reel-sfx place examples/cues.json --duration 6 --out sfx_stem.wav
reel-sfx place cues.json --dialogue voice.wav --out mix.wav   # ducked under the voice, mixed
```

A cue file is a JSON list. `t` is in seconds on your video's timeline:

```json
[{"t": 0.50, "id": "whoosh.soft"},
 {"t": 0.90, "id": "pop.short", "gain_db": -2, "pan": -0.3},
 {"t": 4.50, "id": "riser.noise"},
 {"t": 4.50, "id": "impact.sub"}]
```

Each sound has an **anchor**: its onset, the peak of a whoosh, or the end of a riser. `place()` lands that
anchor on `t`, sample-accurately. So in the file above, the riser *ends* on the reveal exactly where the impact
starts.

```python
import reel_sfx

stem = reel_sfx.place([{"frame": 45, "id": "whoosh.air"}], duration=10, fps=30)   # frame-accurate
voice, sr = reel_sfx.read_wav("voice.wav")
reel_sfx.write_wav("mix.wav", reel_sfx.mix(voice, stem, sr, duck_db=6), sr)

y, anchor = reel_sfx.render("bleep.censor", dur=0.42)    # recipes take parameters too
```

On a video, with ffmpeg: `python examples/sfx_on_video.py my_edit.mp4 cues.json my_edit_sfx.mp4`. It copies the
video stream untouched and ducks the SFX under the video's own audio.

All sounds, with anchors and suggested levels: [docs/SOUNDS.md](docs/SOUNDS.md).
